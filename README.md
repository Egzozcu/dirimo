# Dirimo - Advanced Network Scanner

Dirimo is a Python-based advanced network scanner designed for security research, auditing, and network diagnostics. It includes various scanning techniques such as ARP scanning, ping scanning, threaded port scanning, and JSON output support.

## Features
- ARP scanning for device discovery
- Full scan mode (ping + port scan)
- Threaded fast scanning
- Custom port lists and port ranges
- JSON result output
- Clean tabulated output
